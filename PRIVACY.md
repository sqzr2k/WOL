# Privacy

WOL does not collect personal data and does not use accounts, analytics, telemetry, advertising, or tracking SDKs. The app does not transmit usage data to the developer or third parties.

Device definitions, groups, settings, and optional SecureOn values are stored locally on the Android device. WOL performs network operations only for user-configured Wake-on-LAN packets, online status checks, LAN scans, and network route discovery.

CSV import and export occur only after an explicit user action through Android's system file picker. Users control where exported files are stored or shared.
